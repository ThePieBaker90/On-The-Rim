Weapons with the spin-up property must have the spun-up condition in order to be fired (used for a ranged attack in any fire mode), unless explicitely stated otherwise.
Weapons with this property gain the spun-up condition when the user performs the spin-up action with the weapon.
Weapons with the spun-up condition lose the condition at the end of the user's turn if the user has not used either the spin-up or attack actions this turn.

In simpler terms:
- miniguns must be spun before attacking
- miniguns stay spun so long as they are fired or kept spinning
- if a minigun isn't fired or spun up it stops spinning and needs spun up again before shooting again
