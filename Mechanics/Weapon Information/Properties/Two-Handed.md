### Firearms
- Normal opeeration when used with two hands
- If used with one hand, recoil is doubled
- If used with one hand, one level of [Hipfire Penalty](/Mechanics/Weapon%20Information/Mechanics/Hipfire%20Penalty.md) is applied
- Typically longer reload (action)
- Some weapons may not be possible to use in one hand, these should be specified
