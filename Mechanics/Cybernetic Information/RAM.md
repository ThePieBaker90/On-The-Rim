## RAM Overview
- Certain [[Cybernetics]] need RAM to use their abilities or passives. RAM is a resource that must be [[#Allocating RAM|Allocated]] to be used and [[#Freeing Up RAM|Freed Up]] before it can be reallocated.

## Allocating RAM
- Allocating RAM can be done at any time to any available RAM. When allocating RAM to a [[Cybernetics|Cybernetic]], the allocated RAM becomes unavailable and must be [[#Freeing Up RAM|Freed Up]] before it can be allocated again.
## Freeing Up RAM
- RAM is automatically frees itself up shortly after the ability is was used for ends. Once the  ability the RAM was [[#Allocating RAM|Allocated to]] ends, the RAM must wait it's [[#Cooldown Time]] before it is freed up and can be [[#Allocating RAM|Allocated]] again.
### Cooldown Time
- All sources of RAM have an indicated cooldown time, this during this time the ram is considered unavailable and cannot be allocated. This unavailable time lasts until the start of the creature's $n$th turn where $n$ is the indicated cooldown time.
