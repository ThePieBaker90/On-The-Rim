## RAM Overview
- Certain [[Cybernetics]] need RAM to use their abilities or passives. RAM is a resource that must be [[#Allocating RAM|Allocated]] to be used and [[#Freeing Up RAM|Freed Up]] before it can be reallocated.

## Allocating RAM
- Allocating RAM can be done to any available RAM. When allocating RAM to a [[Cybernetics|Cybernetic]], the allocated RAM becomes [[#Unavailable RAM]] and must be [[#Freeing Up RAM|Freed Up]] before it can be allocated again.
	- RAM can be allocated at any time during the user's turn unless indicated by the ability.
- An ability must not be in effect or be triggering to have RAM allocated to it.
## Unavailable RAM
- While allocated to a [[Cybernetics|Cybernetic]], RAM is unavailable. This means it cannot be [[#Allocating RAM|Allocated]] and does not start its [[#Cooldown Time]] to be [[#Freeing Up RAM|Freed Up]].
- An ability that [[#Allocating RAM|Allocates]] RAM for $n$ turns [[#Freeing Up RAM|Frees Up]] the RAM at the start of the user's $n$th turn.
	- The turn the user uses that ability is considered their 0th turn.
- An ability that [[#Allocating RAM|Allocates]] RAM as an action, bonus action, or reaction [[#Freeing Up RAM|Frees Up]] the RAM at the start of the user's next turn.
## Freeing Up RAM
- RAM is automatically frees itself up shortly after the ability is was used for ends. Once the  ability the RAM was [[#Allocating RAM|Allocated to]] ends, the RAM must wait it's [[#Cooldown Time]] before it is freed up and can be [[#Allocating RAM|Allocated]] again.
### Cooldown Time
- All sources of RAM have an indicated cooldown time, this during this time the ram is [[#Cooling Down RAM|Cooling Down]] and cannot be [[#Allocating RAM|Allocated]]. This lasts until the start of the creature's $n$th turn where $n$ is the indicated cooldown time.
	- The user's turn that the RAM swaps from [[#Unavailable RAM|Unavailable]] to [[#Cooling Down RAM|Cooling Down]] is considered their 0th turn.
### Cooling Down RAM
- While RAM is cooling down after being [[#Unavailable RAM|Unavailable]], it cannot be [[#Allocating RAM|Allocated]] until its [[#Cooldown Time]] passes and it is [[#Freeing Up RAM|Freed Up]].
